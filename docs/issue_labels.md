# Issue Labels

This file documents the labels used for Graft issues to guide contributors and maintainers.

## Priority

- `priority: high` — Important, core functionality or urgent fixes.
- `priority: medium` — Nice to have, may be postponed.
- `priority: low` — Optional, minor tweaks or enhancements.

## Type

- `bug` — An unexpected behavior or failure.
- `feature` — New functionality.
- `enhancement` — Improvement to existing behavior.
- `documentation` — Docs changes or additions.
- `discussion` — Questions, debates, or decisions that need agreement.
- `project-governance` — License, policies, or workflow decisions.

## Status

- `good first issue` — Suitable for new contributors.
- `help wanted` — Issues needing more attention or external help.
- `in progress` — Currently being addressed.
- `done` — Completed and merged.

## Misc

- `wontfix` — Issue acknowledged but will not be implemented.
- `invalid` — Incorrect or irrelevant issue.
- `duplicate` — Duplicate of another issue.
